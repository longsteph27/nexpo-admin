## 🎞️ Animation Timeline

### Section Card Hover

```
Default State
  ↓ 200ms ease-in-out
Hover State
  - Transform: translateY(-2px)
  - Shadow: 0 4px 12px
  - Controls: opacity 0 → 1
```

### Modal Open

```
Closed (opacity: 0, scale: 0.95, y: 20px)
  ↓ 300ms cubic-bezier
Open (opacity: 1, scale: 1, y: 0)
  + Backdrop blur effect
```

### Block Type Card Select

```
Idle
  ↓ On Hover
Scale: 1 → 1.02
Border: neutral-200 → blue-500
Icon Color: neutral-600 → blue-600
  ↓ On Click
Scale: 1.02 → 0.98 (tap feedback)
  ↓ 100ms
Navigate to Editor
```

## 📊 Real-World Examples

Sections used:
1. Hero: Event branding and main CTA
2. Rich Text: Event description
3. Steps: Registration process
4. FAQs: Common questions
5. CTA: Final registration prompt

**Time to build**: ~15 minutes

### Company About Page

Sections used:
1. Hero: Company mission
2. Rich Text: History and values
3. Columns: Key achievements
4. Team: Team members
5. Quote: Founder's message

**Time to build**: ~20 minutes

### Product Features Page

Sections used:
1. Hero: Product headline
2. Columns: Feature details (4-6 rows)
3. Video: Product demo
4. Testimonials: Customer reviews
5. CTA: Free trial signup

**Time to build**: ~25 minutes
